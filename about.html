关于皮蛋工作室

🎮 我们是谁

皮蛋工作室（Pidan Workshop）是一个专注于游戏开发和创意应用的独立工作室。 我们相信"Making game is the greatest game, ever"——制作游戏本身就是最好的游戏。

💡 我们做什么

  • 游戏开发：使用Defold等现代游戏引擎创作有趣的游戏
  • 创意应用：开发各种实用和有趣的互动应用
  • 技术分享：通过博客分享开发经验和技术心得
  • 开源项目：参与开源社区，贡献代码和创意

🛠️ 技术栈

游戏开发

Defold, Unity, Godot

前端开发

HTML5, CSS3, JavaScript

其他工具

Git, GitHub, VS Code
